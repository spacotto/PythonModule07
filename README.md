# PythonModule07

**DataDeck, Master the Art of Abstract Card Architecture.** Welcome to DataDeck - the ultimate card game engine! Master Python’s abstract classes and interfaces by building a modular trading card system. Learn to create flexible, extensible game architectures through progressive challenges covering abstract base classes, multiple inheritance, and interface composition.

## Instructions

Git clone the repository:

```bash
git clone https://github.com/spacotto/Python_Module07.git
```

Execute the module tester:

```bash
python3 -m exN.main
```

>[!NOTE]
>Change N with the number of the module. For example, `python3 -m ex0.main`
